# Schwarzwald color playground

Open `color-lab.html` directly in a browser. It is self-contained, works offline,
and starts with the website colors selected in this exploration. No server or
Amp account is required.

- Click an element in the preview to edit its normal and hover colors.
- Use the palette, color picker, or hex field; the preview updates immediately.
- Switch between the homepage, article, and syntax scenes, or try a narrow width.
- “Compare with Today” and reset use the original, pre-change website colors.
- Export JSON to save a new set of choices; import JSON to restore it.
  `website-colors.json` preserves the selected settings applied to the website.
- Export CSS to obtain the corresponding styles. Playground edits do not modify
  `style.css` or persist automatically when the page is closed.

The preview is a frozen snapshot, not a live rendering of the repository's pages.
Its fonts, icons, examples, and fixed Schwarzwald syntax colors are embedded in
the HTML. Future site layout changes will not automatically appear here.
